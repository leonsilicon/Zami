## Review notes

Zami is a Matrix client. The reviewer signs in directly to the listed homeserver. The app bundles its own interface and supports Matrix rooms, spaces, threads, encryption, and optional native notifications. It has no digital purchases or advertising. The iOS release runs only plugins bundled with the app.

- **Report or block.** Press and hold another member’s message, open the message actions and choose **Report message**. Reports go to the account’s Matrix homeserver. Tap a sender’s avatar to open their profile and choose **Block**. Use **App Settings → Privacy & Safety** to manage blocks and configure muted phrases. A filtered message stays in place so its report action remains available.
- **Delete an account.** Open **App Settings → Account → Delete account**. For password accounts, enter the displayed Matrix ID and the account password. The app requests erasure of message content by default. For delegated sign-in, use the provider’s deletion action when advertised. Provider capabilities and federation affect what the homeserver can erase.
- **Control permissions.** Notifications are optional. Camera and microphone are used when a user starts a feature such as a call, voice recording, or QR sign-in. Location is requested in the location picker, and a user chooses when to share it.

## Guideline review

| Apple guidelines                              | Assessment                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1.1–1.7 Safety                                | Matrix reports and blocks are available in the app. Zami adds local phrase filtering and the app links to published support and community rules. The release omits automatic third-party link previews, the public GIF feed and executable game and Flash embeds. Zami needs an operating escalation process and timely responses under 1.2. A local phrase filter can hide matching messages in the conversation and thread timelines. It does not moderate every homeserver or screen all media and other views. Independent homeservers and room moderators handle server-side enforcement. Kids Category, regulated advice and crime reporting features are outside this release. |
| 2.1–2.4 Completeness, metadata and devices    | Use a final production build, the URLs above, accurate screenshots and a working reviewer account. Verify sign-in, sync, settings, notifications, calls and permissions on supported iPhones and iPads. Use TestFlight for beta distribution.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 2.5 Software requirements                     | iOS uses WKWebView for the bundled client. External plugin install, refresh and startup are disabled in the iOS release, its content policy blocks remote frames and blob scripts, and the general-purpose native plugin bridge is absent. Crypto and media workers are bundled. Test IPv6-only network access against the reviewer homeserver and test native push and calls on physical hardware.                                                                                                                                                                                                                                                                                   |
| 3 Business                                    | Zami has no ads, paid unlocks or in-app purchases. A Matrix account is supplied by the user’s chosen homeserver.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| 4.1–4.3 Design and minimum functionality      | Paper changes navigation, conversations, composer, sign-in, typography and color. Zami uses its own app name and icon. The app bundles a Matrix client with native notifications, authentication callbacks, file picking and background audio. Only the production bundle ID is intended for public distribution.                                                                                                                                                                                                                                                                                                                                                                     |
| 4.4–4.10 Extensions, other software and login | There are no App Store extensions or Apple Pay flows. iOS release add-ons are bundled. Under 4.8, users authenticate directly with their Matrix service. The iOS manifest discloses the push token, account identifier and related identifiers/counts used for optional push. Confirm the final App Privacy label against the signed archive and the policies and retention of third-party services. Confirm deletion on the review homeserver and any provider promoted for account creation. [Apple account deletion guidance](https://developer.apple.com/help/app-review/guideline-reference/5-1-1-account-deletion/), [Apple App Privacy details](https://developer.apple.com/app-store/app-privacy-details/)                                                              |

Preserve upstream attribution and document permissions for third-party services and assets if Apple asks.
